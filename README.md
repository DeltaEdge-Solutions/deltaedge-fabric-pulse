\# Fabric Pulse by DeltaEdge Solutions

**ACI Fabric Health & Automation Readiness Reporter**

Fabric Pulse connects to your Cisco APIC via REST API
and generates a comprehensive, self-contained interactive
HTML report covering:

- Complete fabric inventory — nodes, tenants, EPGs,
  access policies
- Fault analysis with operational impact and
  urgency classification
- Automation readiness score across 7 criteria
- Prioritised remediation guidance (Pro)

No agent. No cloud. No data leaving your environment.
